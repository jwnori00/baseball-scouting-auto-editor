Baseball Scouting Auto Editor v0.2.0 — Windows x64 portable

1. BaseballScoutingEditor-Windows-x64.zip 전체를 새 폴더에 압축 해제하세요.
2. BaseballScoutingEditor 폴더의 BaseballScoutingEditor.exe를 더블클릭하세요.
Python, FFmpeg, pip 설치나 setup_windows.bat/run.bat 실행은 필요 없습니다.
EXE와 _internal, licenses, corresponding-source를 함께 보관하세요.
지원: Windows 10 22H2 / Windows 11 x64.

원본 영상 하나 선택 → 투수 이름/날짜 입력 → 투구 시작/종료 지정 → 투구 추가.
각 구간을 미리보기하고 검토 상태를 '검수 완료'로 바꾼 뒤 수정 적용하세요.
3~5개 투구를 먼저 시험하고 프로젝트를 저장한 뒤 '최종 MP4 저장'을 누르세요.
기본 파일명: 선수이름_YYYYMMDD_Scouting.mp4
기본 출력은 최종 영상 하나입니다. '투구별 MP4도 저장'을 선택하면 개별 클립도 보관합니다.
원본은 수정하지 않습니다. 다른 영상은 별도 프로젝트로 작업합니다.
AI 자동 투구 탐색은 아직 구현되지 않았습니다.
실제 경기영상 정확도와 Shotcut 호환성은 별도 검증 대상입니다.

로그: %LOCALAPPDATA%\BaseballScoutingEditor\logs\application.log
코드 서명 상태: signature-report.json. 파일 출처와 SHA256을 확인하세요.
문제 발생 시 로그와 portable-test-report.json을 개발자에게 전달하세요.
로그에는 로컬 파일 경로가 포함될 수 있습니다.
